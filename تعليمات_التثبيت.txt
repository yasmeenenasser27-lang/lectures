جدول المحاضرات - تطبيق PWA
==============================================

📁 الملفات المطلوبة (ضع كلها في نفس المجلد):
  1. app.html ← الملف الرئيسي
  2. manifest.json ← إعدادات التطبيق
  3. sw.js ← العمل بدون إنترنت
  4. eng.png ← الصورة

🚀 طريقة الاستخدام:
  1. حمّل جميع الملفات
  2. ضعها معاً في مجلد واحد
  3. افتح app.html في المتصفح
  4. تمتع! 😊

📱 تثبيت على الموبايل:
  • iPhone: Safari → Share → Add to Home Screen
  • Android: Chrome → Menu → Install app
