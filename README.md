# 📱 جدول المحاضرات - تطبيق ويب تقدمي (PWA)

## ✨ المميزات

✅ **يعمل بدون إنترنت** - جميع البيانات محفوظة محليًا  
✅ **تطبيق موبايل حقيقي** - يمكن تثبيته على الهاتف  
✅ **سريع وخفيف** - بدون أي مكتبات خارجية معقدة  
✅ **آمن** - كلمة مرور للإدارة فقط  
✅ **مسؤول على الموبايل والويب** - يعمل على أي جهاز  

---

## 📥 كيف تثبت التطبيق على هاتفك؟

### **iPhone / iPad:**
1. افتح `app.html` في Safari
2. اضغط على مربع المشاركة (↑)
3. اضغط "Add to Home Screen"
4. اختر الاسم وأضفه

### **Android:**
1. افتح `app.html` في Chrome
2. اضغط الـ Menu (⋮) في الأعلى
3. اختر "Install app" أو "Add to Home Screen"
4. اضغط Install

---

## 🎯 الملفات المطلوبة

| الملف | الوصف |
|------|-------|
| `app.html` | الملف الرئيسي للتطبيق |
| `manifest.json` | إعدادات التطبيق والأيقونة |
| `sw.js` | خادم العمل (يسمح بالعمل بدون نت) |
| `eng.png` | صورة المدرس (الأيقونة) |

**ضع جميع هذه الملفات في نفس المجلد!**

## 💾 البيانات

جميع البيانات تُحفظ في **متصفحك فقط** (localStorage)
- لا تُحتاج انترنت للعمل ✅
- البيانات تبقى حتى لو أغلقت التطبيق
- كل جهاز له نسخة خاصة به من البيانات

## 📋 نصائح

- 📱 جرّب التطبيق على موبايل حقيقي لأفضل تجربة
- 🔐 غيّر كلمة المرور إذا أردت (ابحث عن `mennayasmine2710` في `app.html`)
- 🎨 يمكنك تغيير الألوان والخطوط في قسم `<style>`
- 📸 غيّر الصورة بصورتك أو شعار مختلف (استخدم `eng.png`)

---

## 🐛 استكشاف الأخطاء

**المشكلة:** التطبيق لا يحفظ البيانات
- **الحل:** تأكد أن localStorage مفعّل في المتصفح

**المشكلة:** الصورة لا تظهر
- **الحل:** تأكد أن `eng.png` في نفس مجلد `app.html`

**المشكلة:** الزر 🔐 ما يشتغل
- **الحل:** افتح Developer Tools (F12) وشُف الـ Console

---

## 📞 الدعم

إذا حصلت مشكلة:
1. افتح F12 (Developer Tools)
2. اذهب إلى Console
3. شُف الأخطاء الظاهرة
4. حاول تحديث الصفحة
